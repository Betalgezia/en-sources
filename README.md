# EN Sources — зарубежные торрент-источники для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa) добавляет зарубежные торрент-источники с контентом на английском языке (фильмы, сериалы, аниме).

## Установка

1. Откройте Lampa
2. **Настройки → Расширения → Добавить плагин**
3. Вставьте ссылку:
   ```
   https://betalgezia.github.io/en-sources/en_sources.js
   ```
4. Перейдите в **Настройки → Парсер** и включите **«Зарубежные источники»**

## Как работает переключатель

- **ВЫКЛ** — поиск торрентов только в стандартных источниках Lampa (ваш парсер/Jackett)
- **ВКЛ** — поиск на зарубежных трекерах с английским контентом
- **«Объединять со стандартными»** — зарубежные результаты добавляются к стандартным, а не заменяют их

## Источники

| Источник | Контент | Примечание |
|---|---|---|
| **Torrentio** | кино, сериалы | агрегатор, нужен IMDb ID карточки |
| **Nyaa.si** | аниме | категория English-translated (RSS) |
| **AniDex** | аниме | официальное JSON API |
| **YTS** | фильмы | оригинальная английская озвучка |
| **EZTV** | сериалы | нужен IMDb ID, фильтр по сезону/серии |
| **TorrentGalaxy** | всё | часто блокируется Cloudflare, по умолчанию выключен |

## Требования

- Настроенный **TorrServer** (или другой торрент-движок) для воспроизведения
- **CORS-прокси** для Nyaa/TorrentGalaxy на Web/WebOS/Tizen (по умолчанию `corsproxy.io`, меняется в настройках; на Android не требуется)

## Возможные проблемы

- **«Script Error» при добавлении плагина** — GitHub Pages ещё не задеплоился. Проверьте, что ссылка открывается в браузере и отдаёт JS-файл (Settings → Pages → ветка `main`, папка `/ (root)`)
- **Нет результатов** — включите переключатель в Настройки → Парсер; для Torrentio/EZTV в карточке должен быть IMDb ID
- **Прокси не работает** — замените в настройках на `https://api.allorigins.win/raw?url=` или свой Cloudflare Worker
